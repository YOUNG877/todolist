## 1. 这个软件是干什么的

一个**以「今天」为中心**的待办清单。它和普通待办应用最大的区别是：

- **待办池**装「想做但还没安排到某一天」的事。你不必一上来就决定哪天做。
- 每天从池子里挑几件**安排到今日**，今天只面对这几件。
- 打勾完成 → 自动归档到那一天。
- **没做完的自动顺延到第二天**，并记录顺延了几天——不会悄悄消失。

一句话：**池子收想法，今天做事情，日历留记录。**

## 2. 安装与启动

### 方式一：安装包（推荐）

双击 `TodoList-x.y.z-setup.exe`，按提示选择安装位置即可。安装后桌面和开始菜单会有「今日待办」。

> **如果弹出蓝色的「Windows 已保护你的电脑」**
>
> 这不是安装包坏了，而是它没有代码签名证书（个人打包的 exe 首次运行都会遇到）。
> 点弹窗里的 **「更多信息」** → 再点 **「仍要运行」** 即可。
> 详细说明与彻底解决（代码签名）见 README 的「双击安装包被 SmartScreen 拦下怎么办」。

### 方式二：免安装绿色版

解压 `TodoList-x.y.z-portable.zip` 到任意目录，双击里面的 `今日待办.exe`。
不写注册表、不建快捷方式，删掉目录就等于卸载。

### 升级

直接安装新版会覆盖程序，**待办数据保留**（数据不在安装目录里，见第 13 节）。

> ⚠️ **同一时间只能运行一个实例。**
>
> 注意：点窗口的 ✕ 只是把程序收进托盘，**程序仍在运行**（见第 12 节）。
> 这种情况下双击新版本的 exe，新版本不会启动——从 v0.4.1 起会弹窗告诉你
> 「今日待办已经在运行」，并且如果版本不同还会说明当前运行的是哪个版本。
>
> **正确做法**：在托盘图标上右键 → **退出**，然后再双击新版本。
> 数据不会丢，两个版本用的是同一份待办数据。

## 3. 界面总览

顶部有两个页签：**今天** 和 **回顾**。

### 今天（三栏）

| 区域 | 放什么 |
| --- | --- |
| **待办池**（左） | 想做但还没排期的事。在这里挑任务安排到今日 |
| **今日待办**（中） | 今天要做的。带进度、排序、子任务 |
| **今日已完成**（右） | 今天已打勾归档的。可以追踪结果或退回重做 |

### 回顾（单栏）

日历热力图 + 月度统计 + 任意一天的完成清单 + 回收站 + 导出入口。
**历史完成记录只在这一页**，不会混进「今天」页。

### 顶栏右侧

| 按钮 | 作用 |
| --- | --- |
| `# 标签` | 按标签筛选任务、进入标签管理 |
| `🐞 时间调试` | 把「今天」往后推几天，用来验证顺延（第 14 节） |
| 🌓 | 亮色 / 暗色主题切换 |
| `⋯` | 导出数据、导出/导入 JSON、清空数据 |

## 4. 五分钟上手

1. 在**待办池**的输入框里敲一条想做的事，回车。
2. 重复几次，攒几条。
3. 勾选左边的小方框挑出今天要做的，点 **「安排选中的 N 个到今日」**
   （或者直接点某条后面的 **「→ 今日」**）。
4. 到中间的**今日待办**里干活。做完了点条目左边的圆圈打勾。
5. 打勾的任务出现在右边的**今日已完成**里。

第二天打开软件，昨天没做完的会自动出现在今天的列表里，并带一个「顺延 N 天」的角标。

## 5. 待办池

输入框在面板顶部，**敲完回车**就添加（也可以点「添加」按钮）。

每条任务上的控件：

| 控件 | 说明 |
| --- | --- |
| 行首**方框** | 批量选择框。勾上几条，再点底部「安排选中的 N 个到今日」 |
| 标题 | **点标题**打开编辑弹窗（优先级、标签、备注、截止日期等） |
| `＋` | 添加二级任务（子任务） |
| `→ 今日` | 直接把这一条安排到今天 |
| 行尾**圆圈** | 直接标记完成（没排期就做完了的情况） |
| `✕` | 删除（进回收站，可恢复） |

面板右下角两个按钮：

- **安排选中的 N 个到今日** —— 只安排打了方框的
- **全部安排到今日** —— 整个池子一次搬完（会先确认）

标题栏右侧的 **全选** 复选框可以一次勾上整个池子。

> 如果这一栏里还有「已排期（未来 N）」分组，说明有任务被安排到了以后某天，它们会在那天自动进入今日待办。

## 6. 今日待办

### 排序

标题旁的排序下拉，四种方式：

| 选项 | 说明 |
| --- | --- |
| 手动排序 | 用 `↑` `↓` 自己调，默认方式 |
| 按优先级 | 高 → 中 → 低 → 无 |
| **按截止日期** | 有截止日期的按日期由近到远排前面，**没设截止日期的排最后**；同一天的按手动顺序 |
| 按创建时间 | 先创建的在前 |

### 进度（0–100%）

每条任务下面有一个 **进度** 滑块：

- 拖到任意位置即时保存，右侧显示百分比
- 适合「做了一半」「大概七成」这类任务
- 进度和「完成」是两件事：进度 100% 不会自动打勾，打勾也不会改进度
- 不在今日列表里的任务，如果进度大于 0，会显示一个 `完成 NN%` 的角标

### 二级任务（子任务）

点任务后面的 `＋` 会出现一个缩进的输入框，输入子任务标题后**回车**，可以连续录入，按 `Esc` 收起。

- 父任务下面会显示 `子任务 1/3` 的进度角标
- **子任务跟着父任务走**：父任务在今日，子任务就在今日；父任务顺延，子任务一起顺延
- 勾完所有子任务，父任务会**自动完成**（可在设置里关掉）
- 取消勾选某个子任务，父任务会自动变回未完成
- 给一个**已完成**的父任务加新子任务，父任务会自动回到未完成

> 统计和日历只数**顶层任务**，子任务不会额外算一件。

### 其他操作

- **点标题** → 编辑弹窗
- **移回池子** → 今天不做了，放回待办池（不产生顺延记录）
- `↑` `↓` → 手动排序
- `✕` → 删除

## 7. 完成任务：归档、追踪、退回

点条目左边的圆圈打勾，任务立即归档到**今天**，出现在右侧「今日已完成」里，并记录完成时间。

### 待追踪（事情做完了，但结果还要盯）

有些任务本身做完了，但结果还需要继续跟进（比如「提交申请」做完了，还要等审批结果）。
在「今日已完成」里点那条任务的 **追踪** 按钮：

- 按钮变成 **追踪中**，条目左侧出现一道**紫色标记**
- 出现一个独立的 **追踪** 滑块（0–100%），和完成进度互不影响
- 条目上显示 `待追踪 60%` 这样的角标
- 再点一次 **取消追踪**，追踪进度清零（**已写的追踪备注会保留**）

### 追踪备注（一条条记录进展）

开启追踪后，滑块下方会出现备注输入框：

```
追踪  ━━━━━━━━━━━●━━━━━━━  90%
23:38  30%  已把材料发给对方，等回执        ✕
23:38  60%  对方确认收到，进入初审          ✕
23:38  90%  初审通过，等最终签字            ✕
┌────────────────────────────┐
│ 记一条追踪进展，回车保存      │ [添加]
└────────────────────────────┘
```

- 输入内容后**回车**保存，可以连续写多条
- 每条备注自动记下**写入时间**和**当时的追踪进度**
  —— 回看时能看出进展轨迹，而不是一串没有上下文的文字
- 鼠标移到某条备注上，右侧出现 `✕` 可以删掉它
- 条目上会显示 `追踪备注 3` 的数量角标
- 空白内容不会保存

> 备注上限 200 条/任务，单条截断到 500 字。
> 关闭追踪不清空已有备注——它们是历史记录。

### 退回今日（重新做）

点 **退回今日**，任务从「已完成」回到**今日待办**：

- 完成时间和完成日期清空
- **进度和追踪标记会保留**（只是重新打开，不是重置）
- 顺延天数不变

> 直接取消勾选（点圆圈）效果一样。两种入口都留着，是因为「退回今日」更明确。

### 回顾里的历史任务

在「回顾」页点某一天，能看到那天的完成清单，同样可以追踪、退回、编辑。

## 8. 回顾页：日历与统计

### 日历

- 每个格子是一天，颜色越深表示那天完成得越多（0 件是灰色）
- 格子默认显示**完成件数**
- 右上角可以切换成**明细**模式，直接在格子里列出那天做了哪几件事
- `‹` `›` 翻月份，**回到今天** 跳回当月
- 点某一天，下方展开那天的完整清单（含完成时间）

### 统计卡片

- **连续完成天数**：一天至少完成 1 件就算连续
- **本月完成** / **活跃天数** / **日均完成** / **完成率**
- **按标签** / **按优先级** 的分布

### 回收站

删掉的任务在这里，可以**恢复**或**彻底删除**。
彻底删除后不可恢复，也不会出现在导出的数据里。

## 9. 标签与优先级

### 设置位置

**点任意任务的标题** → 打开「编辑任务」弹窗，可以设置：

- 标题、备注
- **优先级**：无 / 低 / 中 / 高（显示为条目左侧色条 + `优先级 高` 角标）
- **标签**：最多 5 个。输入后回车添加，已有标签会作为建议列出，点一下即可加
- 截止日期
- 预计耗时（分钟）
- **标记为「必做」**：配合「仅必做任务顺延」策略使用

### 按标签筛选

顶栏 **`# 标签`** 按钮 → 勾选任意几个标签：

- 多选是 **任一命中即显示**（OR）
- 筛选生效时，顶栏下方会出现提示条和「清除筛选」按钮
- 命中的父任务，它的子任务会一起显示
- 筛选**只作用于「今天」页的三个栏**，回顾页始终显示完整历史

### 管理标签

同一个菜单里的 **管理标签…**：

- **重命名**：会把这个标签在所有任务上一起改掉
- **删除**：只把标签从任务上摘掉，**任务本身不会删除**
- 每条标签后面显示有多少个任务在用它

## 10. 导出述职数据

两个入口：顶栏 `⋯` → **导出数据**，或回顾页的 **导出述职数据**。

### 操作

1. 选**时间范围**：本年 / 本月 / 近 30 天 / 自定义（起止日期）
2. 选**格式**：Markdown（.md）或 CSV（.csv，Excel 可直接打开）
3. 勾选是否**附上未完成 / 进行中的任务**、是否**包含备注**
4. 右侧**实时预览**最终内容
5. 点 **下载** 保存文件，或 **复制全文** 直接粘到别处

### 导出内容

- **总览**：累计完成、有记录天数、活跃月份、日均完成、最长连续
- **按月分布**：每个月的完成件数（没有记录的月份也保留一行，便于看趋势）
- **按标签 / 按优先级分布**
- **逐日完成清单**：按日期倒序列出，子任务缩进在父任务下面

> 统计口径：**只数顶层任务**。所以「写周报 + 2 个子步骤」是 1 件，不是 3 件。
> 导出里的时间范围按**完成日期**过滤，与日历显示一致。

## 11. 跨天与顺延规则

### 一天从几点开始

默认**凌晨 4 点**算新的一天。也就是说凌晨 1 点打勾的任务，仍然算「昨天」完成的
（考虑到熬夜干活的情况）。可在「时间调试」面板里改成 0–6 点。

### 一天结束时会做什么

当天没完成的任务，按**顺延策略**处理：

| 策略 | 行为 |
| --- | --- |
| 全部顺延（默认） | 所有未完成任务挪到第二天，顺延天数 +1 |
| 仅必做任务顺延 | 只有标了「必做」的顺延，其余退回待办池 |
| 每次询问 | 不动，等你下次打开时决定（目前是保持原样） |

另外如果设了**顺延上限**（比如 3 天），超过上限的任务会退回待办池，不再无限堆积。

### 周末不算延期

**周六、周日视为节假日，不计入延期天数。** 具体规则：

| 情况 | 顺延天数 |
| --- | --- |
| 周五没做完 → 周六 | **+0**（周末不算） |
| 周五没做完 → 周日 | **+0**（两天都不算） |
| 周五没做完 → 下周一 | **+1**（只有周一算） |
| 周一没做完 → 下周一 | **+5**（跳过中间的周末） |

任务本身**仍然每天都会往前挪**，只是「顺延 N 天」这个计数不把周末算进去。
也就是：周末没干活不会显得你拖了很久。

> 想让周末也算延期：`🐞 时间调试` 面板 → 勾上 **周末也计延期**。

### 顺延角标

- `顺延 2 天` —— 累计顺延的工作日数
- 累计 3 天以上会变红，提示这条已经拖了几天

## 12. 桌面托盘与悬浮小窗

> 仅桌面版（安装包 / 绿色版）有；浏览器里没有托盘。

### 关闭窗口 ≠ 退出

点主窗口的关闭按钮时：

1. 主窗口隐藏到后台，托盘区留一个图标
2. 屏幕**右上角**出现一个小窗，只显示今天的待办

### 悬浮小窗

```
┌─────────────────────────────┐
│ 今日待办 1/5        ⤢  ▴  ✕ │  ← 整条可拖动
├─────────────────────────────┤
│ ▓▓▓░░░░░░░░░░░░░░░░░░░░░░░░ │  ← 完成进度
│ ○ 写周报  子任务 2/3    ✕  │
│   ✓ 汇总本周进度 12:55      │
├─────────────────────────────┤
│ + 加一条今天要做的事…        │  ← 回车即添加
└─────────────────────────────┘
```

| 控件 | 行为 |
| --- | --- |
| `⤢` | 打开主窗口 |
| `▴` / `▾` | 收起 / 展开（收起后只剩标题栏） |
| `✕` | 隐藏小窗（程序仍常驻托盘） |
| 圆圈 | 打勾完成 |
| 底部输入框 | 输入后回车，直接往今天的清单加一条；可连续添加 |

小窗和主窗口用的是同一份数据，在一边打勾，另一边会立刻跟着变。

### 托盘

| 操作 | 行为 |
| --- | --- |
| 左键单击 | 显示 / 隐藏悬浮小窗 |
| 双击 | 打开主窗口 |
| 右键 | 菜单：打开主窗口 / 显示隐藏悬浮窗 / **退出** |

> **真正退出程序只有两个办法**：托盘右键菜单里的「退出」，或在任务管理器里结束进程。
> 只点窗口的 ✕ 是退不掉的——这是故意的，为的是随时能看见今天的待办。

## 13. 数据存在哪、怎么备份

### 存储位置

```
%APPDATA%\TodoList\
```

待办数据存在这个目录下的 `Local Storage` 里（应用用的是 `app://local` 这个来源）。

- **升级、重装安装包都不会丢**（安装目录和这个数据目录是分开的）
- 卸载时默认**保留**数据，只有你手动删掉上面这个目录才会清空
- 数据在**正常退出时**落盘；直接杀进程可能丢失最近几秒的改动

### 备份与迁移

顶栏 `⋯` 菜单：

| 功能 | 说明 |
| --- | --- |
| **导出 JSON** | 把全部数据（任务 + 历史快照 + 设置）存成一个 JSON 文件 |
| **导入 JSON** | 从文件恢复。**会覆盖当前数据**，建议先导出一份 |
| **清空数据** | 删除所有任务与历史，慎用 |

换电脑时：先在旧机器上导出 JSON，在新机器上导入。

> 导出的 Markdown / CSV 只是给人看的报告，不能用来恢复数据。要备份请用 JSON。

## 14. 验证顺延：时间调试面板

不用改系统时间就能验证跨天顺延。点顶栏 **🐞 时间调试**：

- **+1 天 / +7 天**：把「今天」往后推
- **重置为真实时间**：恢复
- **顺延策略**、**顺延上限**、**周末也计延期** 也在这里改
- 下方表格是每天的快照：计划件数、完成件数、顺延出、退回池

> 时间旅行期间**不会写入磁盘**，所以刷新页面或重启程序都不会把数据弄乱。
> 点「重置为真实时间」后回到正常状态。

## 15. 常见问题

**Q：昨天没做完的任务不见了？**
A：看今日列表里有没有「顺延 N 天」角标。如果策略是「仅必做任务顺延」，没打「必做」的任务会被退回**待办池**，去池子里找。如果设了顺延上限，超过上限的也会回池子。

**Q：为什么凌晨做的任务算昨天？**
A：一天默认从凌晨 4 点开始算。可在「时间调试」里把界点改成 0 点。

**Q：删除的任务能找回吗？**
A：能。「回顾」页底部有**回收站**，可以恢复。彻底删除后不可恢复。

**Q：子任务为什么不单独算一件完成？**
A：统计口径是「顶层任务」。否则一个「写周报 + 3 个子步骤」会被算成 4 件，数字虚高。子任务完成情况用 `子任务 2/3` 角标体现。

**Q：进度调到 100% 为什么不自动打勾？**
A：两个概念。进度表示「做到哪一步」，完成表示「这件事结束了」。有些事进度 100% 还要等结果——那正是「追踪」用的场景。

**Q：关闭窗口后程序还在跑吗？**
A：在。这是设计如此（见第 12 节）。要彻底退出，用托盘右键菜单的「退出」。

**Q：双击新版本的 exe 没反应 / 打不开？**
A：几乎肯定是旧版本还在后台跑着（点 ✕ 只是收进托盘，并没有退出），单实例锁把新版本挡掉了。
从 v0.4.1 起会弹窗提示「今日待办已经在运行」，不再静默无反应。

解决办法：右下角任务栏点小箭头 `^` → 找到「今日待办」图标 → 右键 → **退出**，然后再启动新版本。

> 如果托盘里也找不到图标，用任务管理器（`Ctrl + Shift + Esc`）结束「今日待办」进程即可。
> 数据存在 `%APPDATA%\TodoList`，杀进程不会丢失已保存的数据（可能丢最后几秒的改动）。

**Q：为什么导出里没有某一天的记录？**
A：那天的完成记录可能已经被「彻底删除」，或者任务本身在更早的日期完成。导出的时间范围按**完成日期**过滤。

**Q：安装包被杀毒软件/SmartScreen 拦了？**
A：见第 2 节。这是未签名程序的通用行为，点「更多信息 → 仍要运行」即可。
